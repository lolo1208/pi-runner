# 模型配置与 pi 代理接入

Pi Runner 在 Electron 主进程使用 `@earendil-works/pi-coding-agent@1.1.0` 调用模型。界面通过 IPC 提交任务，pi 的 `AgentSession` 负责流式回复、工具执行、会话历史和上下文压缩。主进程采用 ESM 构建，以加载 SDK。

## 使用步骤

1. 打开「设置 → 模型供应商」，添加供应商连接。Ollama 可以读取本机已安装模型；应用不自动下载或启动模型。
   OpenRouter 输入 API Key 后验证密钥并自动读取目录，连接不会生成模型请求。供应商设置页展示所有支持文字输出和工具调用的模型，不限制厂家、版本或数量，保留免费变体和日期版本。已启用模型置顶并按模型名称排序，不按厂商分组；未启用模型按厂商分组，默认全部收起。列表不分页，可搜索名称、ID 或厂商；搜索时展开匹配分组。新模型默认关闭，启用后进入会话选择器；每个模型可独立配置。刷新保留已配置模型、参数及启停状态，已配置旧型号也继续展示；服务下架的型号标记不可用。
   OpenRouter 未启用模型的厂商名称后显示厂商所属国家的国旗，悬停显示国家名称；尚未确认国家的厂商显示地球图标加「?」。国旗使用本地矢量图，兼容 Windows。以「~」开头的厂商归入对应厂商分组，例如「~anthropic」归入「Anthropic」；模型 ID 保留原值用于调用。此标识表示模型来源，实际数据处理地区由 OpenRouter 路由决定。
   ChatGPT 订阅选择「在浏览器中授权」，或「复制授权链接」后粘贴到浏览器隐私窗口。浏览器回调页只有在令牌交换和加密保存都完成后才显示成功，应用随后自动加载模型；回调页面无法打开时，可在「浏览器未自动返回？」中粘贴完整的本次回调地址。支持取消授权和退出账号，授权链接 10 分钟后作废。
2. 为每个模型分别设置上下文上限、输出 Token、Temperature、超时和推理开关。连接测试通过同一 pi 引擎运行，但不读取聊天历史或启用项目工具。
3. 打开项目并开始对话。模型支持工具调用时，代理可读取文件、搜索、编辑、写入和执行命令；Windows 使用 PowerShell，其他平台使用 Bash。
4. 聊天中实时显示生成的正文和工具执行状态。停止按钮中断模型请求及当前工具；窗口关闭或页面离开也会停止任务。
5. 需要撤销文件改动时，打开快照侧栏，查看差异并选择「回滚最近改动」。

## DeepSeek 官方 API

在「模型供应商 → 添加供应商 → DeepSeek」输入 API Key，应用通过 `https://api.deepseek.com/v1/models` 读取官方模型目录；读取不会生成对话。启用需要的模型，之后可刷新目录或更新供应商密钥。密钥加密保存在本机；统一使用供应商密钥；尚未配置供应商密钥时兼容旧模型独立保存的密钥。目录刷新保留已有模型的参数和启停状态；不再出现在目录中的官方模型标记为不可用。对官方文档明确列出的模型补充上下文、输出上限、输入能力与推理档位，其他型号不推测；已公布型号按官方定价页及当前时间显示高峰或非高峰价格，并自动刷新；非高峰时段半价。高峰为 UTC 周一至周五 01:00–04:00、06:00–10:00，排除中国法定假期，周末调休上班仍按周末处理。内置已核实的 2026 年国务院放假安排；其他年份在无法排除节假日的高峰候选时段暂显示高峰价并标注“待确认”；如当天为节假日，实际适用非高峰价。未知型号不推测价格，实际费用以官方结算为准。推理模式支持关闭、低、高和最高，默认高；输出默认 65,536 Token，最大 393,216 Token，推理与正文共用额度。连接测试仅验证连通性，临时关闭推理，不修改已保存设置。对话和 Agent 使用 pi-ai 的 OpenAI Completions 适配。

## Google AI Studio

1. 在 [Google AI Studio](https://aistudio.google.com/apikey) 创建 Gemini API Key，在「模型供应商 → 添加供应商 → Google AI Studio」输入密钥并连接。
2. 连接仅分页读取官方模型目录，不生成内容、不测试模型调用额度。目录展示已确认支持文字与工具调用的 Gemini 2.0、2.5、3.x Pro/Flash 系列；过滤图片生成、TTS、Live、嵌入等专用模型，不把目录可见误认为账号一定可调用。
3. 新模型默认停用，请启用需要的模型；刷新保留参数与启停状态，下架型号标记不可用。所有 Google 模型共用一个加密 API Key，通过「配置连接」更新，失败不会覆盖旧配置。
4. 使用原生 `google-generative-ai` 协议及官方 `@google/genai@2.21.0` SDK，复用 pi 的流式适配、函数调用、工具结果回传与 thought signature 保存；连接测试、上下文摘要和权限审核同样走原生接口。仅支持 AI Studio，不支持 Vertex AI、OAuth 或自定义 Google 反向代理地址。
5. 价格与配额：模型列表按 Google 官方定价页的内置单价表显示价格等级（标准档、≤200k 输入、文本/图像/视频单价，不含音频与缓存存储）；`-preview`（含日期后缀与裸后缀）归一到同一型号的价格。未公布单价的型号（`gemini-3.5-flash`、`gemini-3.7-flash`）与 `-latest` 热切换别名（指向的底层型号会变化且目录接口不返回该指向）改用“参考估算”：按同代或当前已知最新已公布型号推算，界面明确标注为“参考估算”，并提示实际账单以 Google 结算页为准。不属于上述情形且无数据的型号仍显示“价格未知”。已连接的旧目录在读取时自动补齐单价，无需重新刷新。Gemini API 不提供实时剩余配额接口，输入框下方只展示可确证的上下文上限与最近一轮实际用量，不会推算额度。
6. 输出额度包含思考和正文。Gemini 2.5 使用思考预算，Gemini 3 使用模型对应的推理档位；开启推理时至少设置 1024 Token。具体型号是否可用、地区限制、计费和限额以 Google 项目为准；本地不推算 Google 剩余额度或价格。

**默认参数依据：**

- **推理档位**：按下表逐型号对齐官方文档，不按名称推测。

  旧版本给 Google 模型写入过 2,048 输出额度与 60 秒超时（非推理模型的兜底值）；读取配置时会一次性升级为上述默认值，用户自选的其它取值不受影响。

  | 模型 | 默认 | 可选 |
  | --- | --- | --- |
  | gemini-3.8-flash | 中 | 低 / 中 / 高 |
  | gemini-3.6-flash | 中 | 极低 / 低 / 中 / 高 |
  | gemini-3.5-flash-lite | 极低 | 极低 / 低 / 中 / 高 |
  | gemini-3.1-pro-preview | 高 | 低 / 中 / 高 |
  | gemini-3-flash-preview | 高 | 极低 / 低 / 中 / 高 |
  | gemini-3-pro-preview | 高 | 低 / 高 |
  | gemini-2.5-pro | 开（显示为中） | 低 / 中 / 高，不可关闭 |
  | gemini-2.5-flash | 开（显示为中） | 低 / 中 / 高，不可关闭 |
  | gemini-2.5-flash-lite | 关 | 关 / 低 / 中 / 高 |

  不提供“关闭”的模型不会下发关闭请求，避免服务拒绝或报错；旧配置中残留的不支持档位会回退到官方默认值。官方文档未收录的型号（如 `gemini-3.5-flash`、`gemini-3.7-flash`）不下发任何思考配置，保持服务默认行为，避免发送服务端未声明的参数。
- **连接测试**：Google 的连接测试使用该模型的最低合法推理档，避免高推理档在思考阶段长时间无输出而被误认为卡死。
- **服务繁忙**：Google 返回 503（需求过高）时提示为临时容量波动，建议稍后重试或临时切换模型。未开始输出的请求会自动重试 3 次（指数退避）；服务端建议的等待上限为 8 秒，避免长时间无声等待。已开始输出的流不重试，不会重复计费。
- **输出 Token**：默认取模型目录声明的上限，最多 65,536（与 OpenRouter 同口径），与模型的上限共同夹取。Google 将思考与正文合并计入该额度并作硬截断，因此额度过小时可能只有思考、没有正文；应用会明确报告这种情况，建议提高额度或降低推理档位。
- **上下文上限**：默认采用模型目录返回的 `inputTokenLimit`（权威值）；目录未返回时才回退到本地 64K 估算。
- **温度**：默认不发送，使用 Google 服务默认值（1.0），避免自行覆盖官方推荐值。
- **超时**：默认 120 秒（与 Ollama、OpenRouter 一致），指流式空闲超时，持续输出会重置计时。
7. 支持文字、受支持的图片、音频、视频及 PDF 内联输入；普通文档请转成文本或 PDF。完整内联请求限制在约 19 MB 以内，为 Google 20 MB 请求限制保留余量，超限明确报错，不自动上传文件或静默删除附件。

**网络补丁：** 官方 SDK 不接受外部网络函数，项目通过 `patches/@google__genai@2.21.0.patch` 与 `patches/@earendil-works__pi-ai@1.1.0.patch` 注入。依赖被重新安装或升级后补丁可能失效，此时应用会直接报“Google SDK 的网络注入未生效”，而不是静默回退到 Node 直连；按提示重新运行 `pnpm install` 并重启即可。

**网络说明：** Google 的目录读取与生成请求通过应用的 Electron 网络通道（`net.fetch`，与订阅、OpenRouter 相同，沿用系统代理）发出；通过 `patches/@google__genai@2.21.0.patch` 为官方 SDK 增加客户端级 `fetch` 注入点，不修改全局网络。请求仅允许 `generativelanguage.googleapis.com` 官方域名，禁止重定向并剥离 Cookie。密钥只在主进程交给官方 SDK，生成调用沿用应用的空闲超时与取消信号，目录读取总计超时 60 秒、每页超时 30 秒。

尚未使用真实 Google API Key 联网验收时，需在实际账号上验证连接、流式对话、工具调用、多轮回放和附件输入。

## OpenRouter 使用额度

选中 OpenRouter 模型后，输入框下方显示额度。免费变体（`:free`）和 `openrouter/free` 显示「今日剩余 X 次」，悬停查看已用次数、每日上限与更新时间。次数来自官方 `/api/v1/key` 的 `free_model_daily_requests`，由账号共享，每日 00:00 UTC（北京时间 08:00）重置；部分账号或路由不受该上限约束，上游仍可能限流。

付费模型显示密钥剩余金额，悬停查看密钥金额上限与今日消费。未设置密钥金额上限不代表账户余额无限；账户余额和其他预算仍可能影响调用。选中模型、对话开始或结束、窗口重新获得焦点时刷新，当前会话每分钟自动刷新。缺失数据或读取失败显示未知，不根据本地调用次数推算，读取失败后自动重试。

## 模型价格等级

供应商列表、模型配置标题、默认模型选择和聊天模型选择处，在模型名称后显示价格等级标签；聊天记录不显示。标签采用 `badge-dollar-sign` 图标加等级数字，未知价格使用图标加问号。标签是比较等级，不表示单次调用的美元金额。悬停浮层分栏展示输入、输出单价，下方显示简要评级口径、来源和核对日期。

输入、输出单价以美元／百万 Token 计算，参考成本为输入单价 × 75% + 输出单价 × 25%。零平台调用费显示 `$0`；大于零且低于 0.5 美元为 `$1`，0.5 至低于 2 美元为 `$2`，2 至低于 5 美元为 `$3`，5 至低于 15 美元为 `$4`，15 美元及以上为 `$5`。固定边界不随模型目录增删改变，不计缓存折扣、图片、工具和其他额外收费，也不随推理档位变化。

OpenRouter 的价格来自官方目录，随连接或刷新更新并保存到本地。ChatGPT 订阅只按精确模型 ID 匹配已核对的官方 API 标准模式、短上下文单价，标签明确注明“API 参考价，不代表订阅实际费用”。Ollama 确认本地运行时显示 `$0`，不含硬件和电费；官方云端型号按已核对的常规时段价格精确匹配。无法确认或没有可靠价格时显示“价格未知”，不借用相近型号。内置 API 和 Ollama 云端价格表记录核对日期，随应用版本维护；目录刷新不会自动更新内置表。

## 供应商与参数

| 供应商 | 接口 | 参数适配 |
| --- | --- | --- |
| Google AI Studio | 原生 Gemini API，`@google/genai` | 供应商共用加密密钥；模型目录、`maxOutputTokens`、Temperature、按型号适配思考预算/档位；支持流式工具调用 |
| ChatGPT 订阅 | pi 原生 `openai-codex-responses`，浏览器 OAuth | 自动续期；固定 ChatGPT 地址；Temperature 与实际输出长度由服务决定，回复预留 Token 用于本地预算 |
| OpenAI | Chat Completions；包含非 PDF 文件时使用 Responses | 保留输出 Token 参数选择；Responses 使用 `max_output_tokens` |
| OpenRouter | 固定官方 `/api/v1/chat/completions` | 共用加密 API Key；使用 `max_tokens`，按目录适配温度与最大输出，推理档位仅展示目录明确提供的值 |
| Anthropic | Messages | `max_tokens`、Temperature、图片与 PDF |
| DeepSeek、vLLM、自定义 | 配置的 OpenAI 兼容接口；自定义可选 Anthropic 协议 | 保留 Base URL、模型 ID 和独立生成参数 |
| Ollama | 原生 `/api/chat` | 保留 `options.num_ctx`、`options.num_predict`、Temperature 和 `think`，始终显式下发 `num_ctx`，转换 NDJSON 流供 pi 使用 |

上下文上限用于 pi 的压缩预算；不会作为所有供应商都接受的 HTTP 参数发送。只有 Ollama 的上下文设置还会下发到服务，且本地请求总会带上 `num_ctx`：未配置时使用 16,384 Token 兜底，应用侧窗口按同一数值计算。省略 `num_ctx` 时 Ollama 会用远小于应用预算的服务端默认值截断输入且不报错，表现为模型突然返回空正文。其余供应商未配置且未发现上下文上限时，代理按至少 32,768 Token 的本地预算计算，并为输出预留空间；这不代表服务端模型的真实能力。本地模型建议显式填写上下文上限：模型声明的最大上下文（如 256K）会带来可与显存不适配的 KV 缓存分配。

Base URL 填 API 根地址，不包含具体请求路径。远程地址要求 HTTPS；HTTP 仅允许本机回环地址。应用注入的 HTTP 通道不自动跟随重定向；Google 原生 SDK 使用其自身的网络行为和固定官方服务地址。Temperature 留空时不强行发送。

ChatGPT 订阅与 OpenAI API 配置独立，订阅无需 API Key。登录后优先读取账户模型目录，支持新增模型；目录暂不可用时显示 pi SDK 内置目录并明确提示，可点击「刷新模型」重试。SDK 当前包含 GPT-6.1 Sol、GPT-6 Astra、GPT-6 Luna 等模型，实际可用性取决于账号与客户端权限。刷新目录保留每个模型已有参数。

订阅模型在输入框下显示 **5 小时**、**7 天**剩余百分比，悬浮查看用量和重置时间。额度来自 `/wham/usage`，按服务实际返回的窗口时长匹配；未返回的窗口显示「未知」。当前可见会话每分钟、窗口重新获得焦点及请求结束时刷新，主进程合并并发读取并缓存 30 秒；退出账号清除缓存。读取失败显示中文原因，不推算或虚构额度。

订阅的令牌交换、自动续期、模型目录、额度和推理请求统一使用 Electron 网络通道，沿用系统代理且不发送浏览器 Cookie。浏览器能登录而应用无法交换令牌时，页面与应用都会显示对应的中文原因和 HTTP 状态，不展示授权码、令牌或上游原始正文。模型调用与会话仍由 pi SDK 管理。

## 会话内快捷面板

输入框右下角的模型按钮打开快捷面板。顶部是搜索框和打开模型设置的入口；中部按供应商分组列出所有已启用的模型，每行显示推理强度、图片输入支持和上下文上限，当前会话模型以名称加粗标识（无勾选标记），未下载的本地模型置灰；底部为当前会话模型提供**推理强度**选择，按供应商目录返回的档位显示开关或强度。选择模型或调整推理档位都不关闭面板，需要 Esc、再次点击按钮或点击外部退出。切换模型只影响本次会话，不会改动全局默认模型。面板内的推理修改只重写推理字段，上下文、输出 Token、超时等仍需在设置页调整；任务运行期间快捷面板不可用。

## 会话与附件

界面会话保存在 `~/.pi-runner/conversations.json`；pi 的完整 JSONL 会话保存在 `~/.pi-runner/agent-sessions/`。聊天 ID 对应独立目录，保留工具调用、工具结果、压缩记录和快照关联。首次使用 pi 时导入已有聊天，后续只提交新输入；切换模型仍沿用该聊天的完整代理历史。

会话长期保留，只有用户删除聊天或所属项目时才删除其 pi 会话数据。重启应用后优先恢复 pi 的完整记录；取消后的用户消息与已完成结果也保留。失败或取消时保留草稿。

上下文压缩由 pi 负责，偏好设置中的压缩阈值映射到预留 Token 预算。压缩不删除本地原始记录，旧摘要逻辑不会与生产代理调用同时运行。

附件随消息保存。文本、图片、PDF、音频及其他文件在发送前转换为所选供应商支持的格式；供应商不支持的格式返回中文错误。pi 会话中保留原始附件，内部关联标识不会发送给模型服务。图片、PDF 或音频是否可理解仍取决于所选模型。

## 工具与快照

文件工具按会话权限检查项目内外路径，禁止凭据目录、应用数据、`.git` 元数据、符号链接与目录联接；项目外修改按模式逐次询问、自动审核或直接执行。命令工具以项目为工作目录运行，**这不构成操作系统沙箱**；命令仍具有当前用户的系统权限。没有关联项目的聊天不启用工具。审核模型在“设置 → 通用”单独指定，可选择“关闭”或使用默认模型（默认值）；不可用、请求失败、30 秒超时或使用 ChatGPT 订阅时回退到用户确认。

首次执行编辑、写入或可能修改文件的命令前创建影子快照，git status、git diff 等只读查询不创建；任务结束、失败或取消后尝试保存修改后快照。只有修改前快照成功，工具才开始执行。影子 Git 不修改项目自身的仓库、索引或提交。

回滚先保存保护快照，检查本轮文件是否有后续修改，再仅恢复本轮涉及的文件，支持新增、删除和二进制内容。检测到后续修改时停止回滚。快照沿用既有排除规则：依赖、构建产物、`.env` 与凭证目录不进入快照；这些内容及项目外命令副作用无法通过快照撤销。项目包含未排除的符号链接时，快照会拒绝创建，修改工具因此停止。

改动列表只在展示层过滤项目 `.gitignore` 排除项，快照与回滚仍沿用强制添加策略。被忽略文件不参与每轮计数与列表，但混合轮次的回滚与「还原至此」会一并处理；仅有被忽略文件变化的轮次不显示改动卡片。

## 密钥与请求边界

供应商配置仍保存在 `app.getPath('userData')/model-settings.json`。API Key 使用 Electron `safeStorage` 加密；Renderer 只能看到是否配置密钥。ChatGPT 订阅凭证使用相同的系统安全存储加密，保存于 `app.getPath('userData')/chatgpt-auth.enc`，主进程负责读取和自动续期，退出账号删除凭证。安全存储不可用时拒绝保存，不降级为明文。其他 pi 凭证使用内存存储，不额外写明文 `auth.json` 或 `models.json`。不自动发现或加载机器上的 pi 扩展、技能、模板和其他供应商凭证。

代理任务的超时秒数分别限制每次模型调用，包括上下文压缩中的模型调用；从发起调用到收到完整响应计时，下一次调用重新计时。工具执行、需求确认、计划审阅及快照保存不计入模型超时；一次只运行一个任务。模型输出超过 2 MiB 时中止本次响应。已知密钥回显在流式文本和代理记录写入前脱敏；上游错误正文不会直接展示。

成功的最终回复后不再自动调用模型压缩上下文，需要压缩时在下一次回复前进行。完整结束事件到达前，仅显示正文不能视为模型已完成。完整回复后的资源清理、执行统计或快照保存失败以单独提示呈现，保留成功回复，不将原消息放回重试队列。

新输入及首次迁移历史沿用现有消息和附件大小验证；已经保存的完整历史由 pi 管理，不因界面每轮重复发送全部消息而触发消息数量上限。
