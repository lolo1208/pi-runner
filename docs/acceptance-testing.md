## 2026-10-27 专用下载工具验收

模型通过 `download({ url, path, sha256? })` 下载二进制文件，接入文件写入权限审核和修改前快照。Electron 使用独立匿名 GET 请求通道，不继承模型认证头或 Cookie；逐跳交回工具检查重定向。最多 5 次重定向、60 秒、64 MiB，校验 HTTP 200、非空内容、响应长度、常见图片类型与文件头；可选可信 SHA-256 校验。校验完成并重新检查路径后才替换目标，失败或取消保留原文件并清理临时下载。

`Invoke-WebRequest -OutFile`、`iwr`、参数缩写及 `Invoke-RestMethod` 的同类写入已纳入终端写入拦截。原始的两张 Picsum 图片组合下载指令有回归测试，结果为 `block`，提示改用 `download`。普通读取网页及仅打印命令说明文本不会被误认为下载写入。
