## 自动验证

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm audit
pnpm audit --prod
```

`pnpm check` 聚合类型、测试和构建。审计失败记录依赖与处置结论，不用生产依赖无报告替代全工具链审查。

`tests/shadow-git-manager.test.ts` 覆盖真实 Git 增删改、CRLF 与项目属性规则、中文空格路径、二进制、空快照、重新打开、并发访问、非法提交/路径与元数据联接点，以及回滚和旧快照恢复对当前排除文件的保护。`tests/project-file-capture.test.ts` 验证内置和项目排除规则、跳过目录、增量复制、规则改变、失败重试及大量文件的复制数量与采集耗时。`tests/snapshot-profiles.test.ts` 覆盖扩展语言及框架的嵌套项目识别、同名普通目录保留、Unreal 资源/自动保存/预编译插件保留、Bazel 产物链接、项目标记增删，以及标准缓存签名的有效性和恢复过滤。`tests/project-ignores.test.ts` 覆盖展示规则的目录、通配、否定、锚定、异常路径、缺失规则和缓存失效。`tests/ignored-files-ui.test.tsx` 覆盖整轮被过滤与可见改动为空时的界面表现。尚不等于 A04 的完整跨平台验收。

任务快照回归还覆盖：单条与组合只读 Git 查询不准备修改前基线；自动沙箱的 Git 兼容性修复不增加快照；同内容重写、修改后改回、只生成排除项及无副作用的失败命令不发布对照或移动 HEAD；实际改动可在空历史中发布，前后版本均可还原；基线期间的手动快照不会丢失；收尾采集失败保留私有基线，并可重新打开后重试。覆盖文件为 `tests/tool-permissions.test.ts`、`tests/pi-agent-service.test.ts`、`tests/shadow-git-manager.test.ts`、`tests/sandbox-service.test.ts`。真实 AppContainer/MXC Git 测试仍需显式启用对应环境变量。
