# 使用指南

## 模型配置

1. 打开「设置 → 模型供应商」，添加供应商并配置密钥或服务地址。
2. 连接并启用需要的模型，按需设置上下文上限、输出 Token、超时、温度及推理强度。
3. 创建普通对话或选择项目，在输入框选择模型并发送消息。

连接测试不读取聊天历史，也不启用项目工具。模型和附件能力取决于供应商及具体型号；不支持的附件格式会报错。远程服务地址要求 HTTPS，HTTP 仅允许本机回环地址。

- **Google AI Studio**：使用 Gemini API Key 和官方接口；不支持 Vertex AI、自定义 Google 代理地址或 OAuth。
- **OpenRouter**：使用 API Key 读取模型目录；刷新保留已有配置。额度以服务端返回为准；厂商国家标识不表示请求处理地区。
- **DeepSeek**：使用官方 API Key 读取模型目录。
- **ChatGPT 订阅**：使用浏览器授权，与 OpenAI API Key 独立。
- **Ollama**：可读取本机已安装模型，不自动下载或启动模型；建议根据本机资源设置上下文上限。
- **OpenAI、Anthropic 及兼容服务**：按供应商配置接口、模型 ID 和参数；自定义服务需填写 API 根地址。

模型可用性、额度和价格以供应商为准，价格标签仅供比较。API Key 和订阅凭证由 Electron safeStorage 加密保存；系统安全存储不可用时不会降级为明文。远程模型调用会将提示词、必要的上下文及附件发送给供应商。

## 计划模式

在输入框切换到「计划」并描述任务。助手可读取和搜索上下文，但批准计划前不能写入文件、下载或执行终端命令，即使已开启完全访问也是如此。

不确定的问题会通过选项窗口逐轮确认，也可填写自己的回答。需求明确后，助手提交计划；你可以提出修改意见，或点击「批准计划并开始执行」。批准后仍按当前权限模式执行，具体操作可能需要单独审批。

问题和计划窗口可以收起并重新打开；停止请求会使待处理交互失效。会话保留计划记录，但退出应用后不会自动执行旧计划，需要重新发送消息继续。计划需使用支持工具调用的模型。

## 权限模式

权限按会话保存，任务运行时不能切换。新会话不会自动使用完全访问；同项目已有项目自审或完全访问会话时，新会话默认项目自审，否则默认每次询问。

| 模式 | 行为 |
| --- | --- |
| 每次询问 | 项目内普通文件读取直接执行；项目外读取、文件修改和终端命令逐次确认。 |
| 项目自审 | 可读取有权访问的普通文件；项目和系统临时目录内的普通修改通常直接执行，其余操作按规则或审核模型判断，不确定时询问用户。高风险操作仍可能需要人工确认。 |
| 完全访问 | 切换时确认，保存后继续有效；在当前用户权限下执行，不逐次审批，但仍受公共安全规则和计划模式限制。 |

三种模式均不单独限制联网。文件工具限制凭证、应用内部数据、Git 元数据、链接和特殊文件；已识别的毁灭性命令、直接文件修改和下载落盘命令由公共规则拦截。

项目自审中，已识别的只读查询和常见开发命令可直接执行，具体取决于命令和参数；未知命令、项目外目标、全局安装及其他风险操作进入审核。提权、权限修改和高影响系统管理等操作需要人工确认。审核模型可在设置中关闭、指定或使用默认模型；不可用、超时或结果无效时转交用户。模型审核会将需求和待审操作发送到所选模型服务。

**命令审核不是沙箱。** 项目脚本、安装钩子和子进程仍具有当前用户的系统权限；只对可信项目放行开发命令。文件工具的路径保护不能约束终端程序。
