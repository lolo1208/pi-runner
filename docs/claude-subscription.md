# Claude 订阅（实验性）

## 使用方式

在“模型供应商 → 添加供应商 → Claude 订阅”中：

1. 自动检测官方 Claude Code。未安装时点击“安装官方 Claude Code”，确认后下载并执行官方原生安装脚本（Windows 使用 PowerShell，macOS 使用 curl 和 bash），无需安装 Node.js。也可打开官方指引手动安装，或选择已安装的官方原生程序。
2. 点击“登录 Claude 订阅”，在浏览器完成官方授权。已有订阅登录可直接复用。无法自动返回时重新检测；只有官方 CLI 要求输入授权码时才使用手动提交入口。
3. 点击“绑定订阅并加载模型”，确认风险和计费约定。当前 CLI 的模型目录握手必须成功；不使用静态列表冒充账号权限。
4. 选择模型开始聊天。模型高级设置提供上下文、思考档位与空闲超时，输出额度按目录管理。

本次新增能力只有订阅，不需要 API Key，不提供 API 地址，不自动回退 API。项目已有的 Anthropic API 配置保留兼容性，但不是 Claude 订阅的调用路径。

## CLI HTTP 代理

添加供应商或后续配置连接时，可填写“CLI 网络代理（HTTP，可选）”。优先显示已保存的 CLI 代理；未保存时默认使用应用启动环境的 `HTTP_PROXY`，不存在则为空。

- 支持 `127.0.0.1:7890`、`http://127.0.0.1:7890`，统一保存为 HTTP URL。
- 点击“保存代理”，或继续安装、登录、绑定、刷新时，保存已填写的代理到 macOS `~/.claude/settings.json` / Windows `%USERPROFILE%\.claude\settings.json` 的 `env.HTTP_PROXY` 与 `env.HTTPS_PROXY`，保留其他字段。
- 未编辑且留空时不改文件；留空后点击保存会删除这两个配置，不清除其他环境变量。无文件且无需写入时不会创建空配置。
- 同步注入本应用启动的 CLI 子进程环境，回环地址加入 `NO_PROXY`，避免本地模型转发被送往代理。更改代理会清理旧预热进程，新进程使用新配置。
- 此配置是 Claude Code 的共享设置，会影响其他使用者；不会更改 Electron 模型转发的系统代理。外部配置文件修改可在重新启动应用后重新读取。
- 不支持带账号密码、路径或非 HTTP 协议的代理地址。配置 JSON 无效或路径为链接时拒绝覆盖。

## 登录与解除绑定

认证、令牌存储和刷新由官方 Claude Code 负责。Pi Runner 不读取、复制或保存它的凭证文件，也不要求导入订阅令牌。CLI 使用官方的登录存储机制，本应用无法替它承诺具体系统上的存储行为。

- **解除 Pi Runner 绑定 / 移除供应商**：停止本应用调用，移除其模型配置，保留官方 CLI 登录与已有聊天记录。
- **退出共享 Claude Code 账号**：先解除绑定，再执行官方退出；也影响终端及其他使用该登录的工具，操作前再次确认。
- **切换账号 / 重新登录**：清理旧模型和预热进程，完成后重新绑定或刷新模型。模型请求运行期间不可更改账号或绑定。
- 自选可执行路径仅本次运行有效；标准安装位置自动检测。不要选择不可信程序。

## 工具与上下文

模型通信经过真实官方 Claude Code 的 stream-json 协议，不由 Pi Runner 自行模拟 Claude Code 身份头。Pi Runner 保留完整对话、压缩、审批、文件工具和影子快照。Claude Code 原生工具、外部设置来源与额外 MCP 配置关闭，内部 MCP 只列出工具并拒绝执行；实际工具调用回到 Pi Runner 审批。

普通连续对话可以复用进程；工具调用边界、分支、修改历史、配置变化或异常需要重建并回放历史。最多缓存两个进程，最长存活五分钟；并发且无法复用的请求使用一次性进程。不能保证无冷启动开销。停止任务会取消对应上游请求；解绑或退出应用时清理相关进程和本地转发服务。

支持现有文本、图片、PDF 的附件转换；其他不支持的附件明确报错。复杂工具 schema 在上游适配中可能简化。目录元数据不等于服务端保证权限，最终以实际订阅服务响应为准。

## 风险与计费保护

使用官方 CLI 不等于第三方集成获 Anthropic 官方认可，不能保证不封号，也不能保证政策和订阅额度规则长期不变。

- 仅接受 CLI 可识别的 Pro/Max/Team/Enterprise 订阅类型；实际可用性由服务决定。
- 环境中的 API Key、手动 OAuth 令牌、认证代理地址及云平台计费覆盖被拒绝，不会静默换用其他身份。
- 不提供额外付费放行开关。检测到额外额度计费或第三方计费拒绝会停止调用；本次应用运行中锁定后续订阅请求。关闭账户侧额外付费后，需要确认并重新绑定。
- **部分计费信息在响应后才出现，所以首次异常请求可能已经收费。请在 Claude 账户的用量设置中关闭额外付费，不要仅依赖应用拦截。**
- 对话、权限审核、上下文压缩和重放均可能消耗额度。最近调用的额度状态不是实时剩余额度，不编造余额或百分比。

## 网络与安全

模型本地转发仅监听回环地址，使用随机路由，拒绝带浏览器 Origin 的请求，不允许跨地址重定向；认证头只在主进程和官方 CLI 调用链短暂经过，不进入界面与日志。模型转发使用 Electron 网络栈以沿用系统代理，不继承浏览器 Cookie。官方 CLI 的登录与其他自身请求仍使用其网络配置。

安装需要网络和本机权限；自动安装执行官方远程脚本，不会提权，也不需要安装 Node.js。失败后可使用官方原生安装指引。可看到 CLI 版本；旧版协议握手失败时，请更新 CLI。Windows/macOS 的完整安装与实际账号验证仍应在对应平台完成。

## 故障处理

- **未找到 CLI**：重新检测、手动安装，或选择官方原生可执行文件。Windows 手动选择只接受 `.exe`；npm 安装使用标准 PATH 自动检测。
- **登录完成但未绑定**：点击重新检测，再绑定订阅。非订阅账号不会启用。
- **模型目录失败**：检查 CLI 版本、账号、网络后重试；不会伪造可用模型。
- **提示额外计费**：停止重试，检查官方账号使用规则及账户付费开关；确认后再重新绑定。
- **授权超时**：取消后重新登录，或在官方终端完成 `claude auth login` 后回来检测。
